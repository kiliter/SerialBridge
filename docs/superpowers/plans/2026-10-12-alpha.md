# SerialBridge Alpha Implementation Plan

> For agentic workers: execute this plan task by task; retain test results in docs/verification.

**Goal:** Deliver actual source and an evidence-based status report under the exact requested filenames.
**Architecture:** Shared Rust library used by headless CLI and Tauri. TypeScript browser executor and console. Framed peer RPC and bounded binary transfers.
**Tech Stack:** Rust/Tokio/Axum/tokio-serial/reqwest/Tauri 2; TypeScript; native Node test runner.
**Spec:** docs/design/alpha.md and approved-prototype.html. The original v0.3 is historical, not the current architecture.

## Global constraints
- No fixed operating-system roles. Loopback-only service. No Chrome credentials exported.
- Never label simulated UI/API tests as hardware or Rust integration verification.
- No nonexistent download links or unexecuted test claims.

## Review focus
Cancellation during asynchronous permission checks must not issue a request; untrusted filenames cannot escape roots; disconnected peer must not display its last extension as online; unbounded file streams must be rejected; extension acknowledgements must match transfer and offset.

## Tasks
- [x] Tests: write Node tests for browser policy/stream limits/cancellation and UI state. Run RED, implement, run GREEN.
- [x] Core source (Rust build/test NOT verified): config, framing, peer sessions, authenticated API, HTTP/browser executors, file transfer. Add Rust unit/integration tests; compile only if toolchain actually available.
- [x] Extension: pairing/Origin, reconnect/heartbeats, limited fetch, stop-and-wait binary downloads. Build TypeScript and run protocol-level tests.
- [x] UI source + offline DOM tests (Tauri NOT compiled): four pages with live state, logs, settings, pairing and transfers; embed same Rust core. Exercise browser UI via a clearly labelled mock fixture.
- [x] Delivery artifacts and validation procedure: commands/config examples, protocol/API docs, CI, real test logs, status matrix. ZIP test, extract and compare all members; create SHA256SUMS.
