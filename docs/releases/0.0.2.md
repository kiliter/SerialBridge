## SerialBridge 0.0.2

缺陷修复版本，不改变 HTTP API 与线协议，可与 0.0.1 节点互通。

### 修复
- **TCP 转发与 RPC 共用写队列**：转发流量占满串口写队列时，RPC、文件传输不再立即以 `BUSY` 失败，而是排队等待，入队与应答共用调用超时。
- **TCP 转发流泄漏**：`STREAM_OPEN` 之后立即到达的 `STREAM_RESET` 不再被忽略；入站流在读循环中同步登记。
- **`BUSY` 应答丢失**：对端执行槽满时的 `BUSY` 应答改走高优先级控制队列，队列满时延后发送而不丢弃，调用方不再空等到超时。
- **CLI `status` 经代理泄露 Token**：设置 `HTTP_PROXY` 时，携带 API Token 的本机请求不再发往系统代理。
- 手动重连、上传过期清理、生命周期与浏览器扩展等审查问题（`7bfe813`、`2751a0f`）。
