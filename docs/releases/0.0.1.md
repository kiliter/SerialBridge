## SerialBridge 0.0.1

首个正式编号版本，安装包与预发布 `v0.0.1-18ee843` 相同，均由提交 `18ee843` 经 Windows / macOS / Linux CI 测试后构建。

### 新增
- **TCP 转发**：本机监听端口，对端连接目标地址，字节原样透传，可承载 Xray/Mihomo 的 VLESS、TLS、SSH 等任意 TCP 协议。每流独立流控，单流阻塞不影响其它流。
- 控制台新增「TCP 转发」页面与总览卡片；本机 API 新增 `GET /v1/tunnels`。

### 修复
- 发送队列满时 RESET 不再丢失；连接阶段收到异常帧会重置该流。
- 区分对端结束与本地错误的错误码。
- 监听端口被占用时每 3 秒自动重试。

### 安装包
- Windows：`SerialBridge_0.0.1_x64-setup.exe`
- macOS：`SerialBridge_0.0.1_universal.dmg`（未签名/未公证）
- Linux：`.deb` / `.AppImage`
- Chrome/Chromium 扩展：`SerialBridge-Chrome-0.0.1.zip`（开发者模式加载已解压的扩展）

校验和见 `SHA256SUMS`。

### 验证边界
软件链路已通过 loopback 模拟测试和 Xray+Mihomo VLESS 联调；FT232RL 双机实机链路、托盘行为和签名分发尚未验收。
