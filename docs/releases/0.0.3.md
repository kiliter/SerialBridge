## SerialBridge 0.0.3

链路层可靠传输版本。线协议升级为协议 2（`SBR2`），**与 0.0.2 及更早版本不兼容，两端必须同时升级**；HTTP API 不变。

### 新增
- **链路层自动重传**：串口误码导致的 CRC 错误不再断开会话、重置全部 TCP 转发流。帧头与内容分别校验，损坏帧被丢弃后由对端按序号重传（selective repeat，NAK + 超时 + 尾帧探测），接收端按序、去重后交付。
- `/v1/status` 的 `peer.link` 提供损坏帧、NAK、重传累计次数；日志每 10 秒最多一条汇总。
- 收到 0.0.2（协议 1）对端的帧时给出明确提示，而不是反复 CRC 错误。

### 行为说明
- 重传只在同一会话内进行；对端重启或会话超时（25 秒）后在途请求仍然失败，不跨会话重放。
- 误码率过高时有效吞吐会明显下降；长 TTL 线建议从 921600 或 1500000 波特率起步，观察 `peer.link.retransmits` 再调整。

### 安装包
- Windows：`SerialBridge_0.0.3_x64-setup.exe`
- macOS：`SerialBridge_0.0.3_universal.dmg`（未签名/未公证）
- Linux：`.deb` / `.AppImage`
- Chrome/Chromium 扩展：`SerialBridge-Chrome-0.0.3.zip`

校验和见 `SHA256SUMS`。

### 验证边界
本地已通过 Core 单元/集成测试（含注入随机位翻转的链路噪声测试）与真实 headless 双进程 e2e（loopback TCP，含 TCP 转发与对端重启）；FT232RL 双机实机链路、托盘行为和签名分发尚未验收。
